# Подключение WhatsApp к ИИ-консультанту — инструкция для приёмной / IT

> Что нужно сделать сотруднику вуза, у кого есть **доступ к Facebook вуза** и **телефон с номером WhatsApp приёмной**.
> Это разовая настройка. После неё технические шаги доделает Isa (isa.kasymbekuulu@alatoo.edu.kg).
> Регистрировать компанию / проходить верификацию документами на старте **не нужно**.

## Сначала решить (1 вопрос)
Будет ли приёмная **дальше переписываться в приложении WhatsApp** на этом же номере?
- **Да** → на Шаге 4 выбрать режим **Coexistence** (номер останется и в приложении, и в API).
- **Нет, номер отдаём боту** → обычное добавление (номер уйдёт из приложения WhatsApp).

## Шаги

### Шаг 1. Бизнес-портфолио
Зайти на **business.facebook.com** под Facebook вуза → создать/открыть бизнес-портфолио.
Данные (название, адрес, сайт alatoo.edu.kg) — как в документах вуза. Верификацию проходить не обязательно.

### Шаг 2. Аккаунт разработчика
Открыть **developers.facebook.com** → «Мои приложения» → **Создать приложение** →
сценарий «Другое» → тип **Business** → создать.

### Шаг 3. Подключить продукт WhatsApp
В приложении: плашка **WhatsApp → «Настроить»** → слева появится пункт «WhatsApp» → открыть **«Настройка API»**.

### Шаг 4. Добавить номер (нужен телефон!)
«**Добавить номер телефона**» → ввести отображаемое имя (напр. «AlaToo University»), часовой пояс,
категорию, описание → ввести **номер приёмной** → на телефон придёт **SMS с кодом** → ввести код.
(Если нужен Coexistence — выбрать этот режим и отсканировать QR из WhatsApp Business app на телефоне.)

### Шаг 5. Дать доступ Isa
Business Settings (Настройки компании) → **«Люди»** → пригласить
**isa.kasymbekuulu@alatoo.edu.kg** с ролью **Администратор** →
выдать доступ к созданному **приложению** и к **WhatsApp-аккаунту**.

**Готово.** Дальше Isa всё доделает сам, телефон больше не понадобится.

## Если добавить администратором нельзя
Тогда после Шага 4 прислать Isa три значения со страницы «Настройка API»:
- **WhatsApp Business account ID (WABA ID)**
- **Phone number ID**
- **System user token** (постоянный — при создании выбрать срок действия «Никогда»)

> Токен — это секрет (как пароль). Передавать только Isa, не публиковать.
