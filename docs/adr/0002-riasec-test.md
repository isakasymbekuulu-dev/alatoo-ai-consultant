# ADR-0002: Профориентационный тест RIASEC

Дата: 2026-06-10 · Статус: принято

## Контекст
Дипломный проект требует профориентационный тест, интегрированный с ИИ-консультантом:
агент предлагает тест, студент проходит, результаты возвращаются в чат и доступны LLM.
Методика должна быть защищаемой научно.

## Решение

**Методика.** Адаптация **O*NET Interest Profiler Short Form** (Rounds, Su, Lewis &
Rivkin, 2010; U.S. Department of Labor) — 60 пунктов, по 10 на каждый из 6 типов
Голланда (RIASEC), шкала Ликерта 1–5. Обоснование: инструмент находится в public
domain, психометрически валидирован (внутренняя согласованность шкал α ≈ 0.8–0.9 в
оригинальных исследованиях), широко используется в национальной системе
профориентации США (My Next Move). Пункты переведены на русский и кыргызский
(перевод требует экспертной проверки носителем — отмечено как ограничение).

**Скоринг.** Сумма по типу (10–50). Код Голланда = топ-3 буквы, ничьи разрешаются
каноническим порядком R-I-A-S-E-C (стандарт O*NET).

**Маппинг на программы.** Каждой программе бакалавриата Ала-Тоо присвоен
3-буквенный код Голланда (экспертная разметка по кодам типичных целевых профессий
в O*NET). Соответствие = взвешенная конгруэнтность нормированного профиля
пользователя с кодом программы (веса позиций 3/2/1) — упрощённый вариант индекса
конгруэнтности; выдаются топ-6 программ.

**Архитектура.**
- `app/riasec.py` — банк пунктов (ru/ky/en), скоринг, рекомендации.
- API: `GET /riasec/api/questions`, `POST /riasec/api/submit`, `GET /riasec/api/result`.
- Хранение: таблица `riasec_results` в той же SQLite + запись хода теста в
  `messages` (source=`riasec-test`) → результаты видны в `/admin/logs` внутри сессии.
- Интеграция с чатом: результат привязан к `session_id` чата; при каждом запросе
  `/v1/chat/completions` бэкенд подмешивает профиль в системный контекст LLM
  (по `X-Riasec-Id` или по `session_id`). Системный промпт велит агенту предлагать
  тест сомневающимся (`/test`) и работать с результатами.
- UX: `/test` в стиле чата; после теста кнопка «Обсудить с ИИ-консультантом»
  возвращает в чат, карточка результатов появляется в переписке, диалог
  продолжается автоматически. Если тест пройден без чата — создаётся новый чат
  с id сессии теста (один лог на тест+диалог).
- Согласие: отдельная модалка на `/test`; флаг consent сохраняется с результатом.

## Альтернативы
- Self-Directed Search (Holland) — проприетарный, лицензия. Отклонено.
- Собственный опросник с нуля — нет валидации, слабее на защите. Отклонено.

## Ограничения
- Перевод пунктов на ky/ru не проходил психометрическую валидацию на местной
  выборке — в дипломе указать как направление будущей работы.
- Коды программ — экспертная разметка; можно уточнить опросом преподавателей.
