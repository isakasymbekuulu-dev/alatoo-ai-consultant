# ADR 0003 — Переход RAG-пайплайна на LangChain + гибридный поиск

Дата: 2026-06-18. Статус: принято.

## Контекст
Ingestion и retrieval были на собственном коде: ручной upsert через `qdrant-client`,
чисто плотный (dense) векторный поиск BGE-M3, фиксированный чанкинг, метаданные
почти не заполнялись (индексы под `faculty`/`program`/`source_url` создавались, но
пустовали). Работало, но это не продуктовый стек: на точных токенах (номера
кабинетов «A315», телефоны, баллы ОРТ) чисто семантический поиск иногда промахивался.
Решение — перейти на LangChain как зрелый слой retrieval и поднять качество.

## Решение
- **LangChain `QdrantVectorStore` в режиме HYBRID**: два named-вектора —
  `dense` (BGE-M3, cosine) и `sparse` (BM25 через FastEmbed). Результаты сливаются
  Reciprocal Rank Fusion. Гибрид закрывает слабое место dense-поиска на точных токенах.
- **Dense оставлен на BGE-M3** (sentence-transformers) — лучший для ky/ru/en;
  обёрнут в LangChain `Embeddings`. API-эмбеддинги остаются опцией через `EMBED_MODEL`.
- **Чанкинг с учётом заголовков** для Markdown (`MarkdownHeaderTextSplitter` +
  рекурсивный), путь заголовков подмешивается в текст чанка — контекст не теряется
  при разбиении. Прочие форматы — рекурсивный сплиттер.
- **Метаданные**: `source`, `doc_type`, `lang`, `section`, `faculty`, `source_url`,
  `updated_at`; payload-индексы по ним → доступна фильтрация (напр. по `lang`).
- **Коллекция пересоздаётся** при ingest (named-векторная схема), чанки дедуп по хешу.
- Робастная загрузка файлов (кодировки, отсев повреждённых) сохранена — это безопаснее
  generic-лоадеров, учитывая историю с битыми CSV.
- `score_threshold` к гибриду НЕ применяется (RRF-скоры ~0.01–0.03, не cosine);
  ранжируем по `top_k` (поднят 5 → 6).

## Последствия
- Плюсы: выше точность на точных запросах, осмысленные метаданные и фильтры,
  зрелый расширяемый стек (легко добавить multi-query, reranker, self-query).
- Минусы/риски: +зависимости (`langchain-qdrant`, `fastembed`); на сервере при
  первом ingest докачивается модель BM25; LangGraph-граф не тронут (он только
  собирает промпт). Реранкер (cross-encoder) вынесен в отдельную фазу — упирается
  в RAM 2 ГБ; включим при апгрейде сервера.
- Откат: вернуть прошлую версию `app/{rag,qdrant_store,embeddings}.py` и
  `ingestion/ingest.py`, переиндексировать.

## Проверка
- Смоук-тест нового ingest на реальных данных: 16 файлов → 268 чанков, метаданные
  (`faculty`/`section`) заполнены, битые .txt отсеяны.
- Гибридная проводка (named-векторы + RRF + фильтр) проверена in-memory.
- Импорт всех модулей и `pytest` (граф) — зелёные. Финальная проверка — QA-прогон
  после деплоя.
